The design brief, copy-ready for whoever restyles this

Written 2026-11-20 (T-63) and kept in its own marked region, so neither the generated brief above nor a rebuild can drop it. Every line is a rule the build already enforces or a constraint an official source sets. Hand it to a designer as it stands.

ConstraintThe rule, in one lineWhy it is not negotiable
Lead with productsThe first screen shows appliances and buyer questions; the verification surfaces sit one click away in the footer.Owner instruction, recorded in DIRECTION.md. The site is a shop, not an audit.
DisclosureOne strip above the masthead on every page, plus the footer copy, naming the tracking ID.FTC guidance asks for a clear and conspicuous disclosure near the claim it qualifies (S03).
No prices, no ratingsNothing renders a price, star rating or review count; a button opens the listing instead, where the number is current.Program Policies allow price and availability display only when Amazon serves them or they come from Creators API / PA API (S37). Neither applies here.
Buttons are tagged product linksEvery data-event="outbound_click" anchor is amazon.com/dp/<10-char ASIN>?tag=… — no shortener, no untagged link, label and target agree.Participation Requirements 2(a)/2(b) (S37). Gates 7b and P09 fail the build otherwise, so a redesign cannot quietly undo it.
Art, not photographyTypographic and CSS/SVG artwork only. No reused Amazon images, no generated product photographs.Program Content includes images and only Amazon-provided assets may be used (S01, FLG-008).
Attribution is a design elementA seller-stated figure prints with the listing named beside it; a field nobody verified stays visibly blank.The site’s claim is that any number on a page is traceable. Blank beats inferred.
Guides answer a questionOne buyer question per page, an honest limits section, dated sources, and a byline stating what was and was not tested.Gate D40 counts the guides, the cadence document sets one per month, and the byline rule keeps the claim modest.
Light pageOne local stylesheet, one local script, system fonts, no third-party asset requests on shop pages.Verified by URL scan on 2026-11-20. Core Web Vitals remain unmeasured, so no speed claim is made (Q-29).
