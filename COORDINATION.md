# COORDINATION.md — shared task board

This file is the shared task board for every agent session working in this repository.
Read it before you start. Update it when you claim, finish, or hand off work.

## Rules of the board

1. **Claim before you build.** Write your session ID, task, and file scope in the table below,
   commit, and push that claim before you touch any file.
2. **One owner per file scope.** Do not edit a file owned by another session. If a task needs a
   change in someone else's scope, log a request in the *Cross-scope requests* section instead.
3. **Branches.** Each session works on its own branch named `session-<id>/<task>`. The coordination
   table is the only file every session may edit, and only in its own row.
4. **Small, frequent commits.** Run `git pull --rebase` before every push. On a conflict: stop,
   resolve it without discarding the other session's work, and log what happened below.
5. **Never mark anything verified without an official source link.** Record the source in
   `data/sources.json` and reference it from `data/products.json`.
6. **Shared outputs** (`index.html`, `sitemap.xml`, `feed.xml`, navigation) are regenerated by the
   final integration session only, after all other tasks are complete.
7. **Stale claims.** If a session's claim is more than 60 minutes old with no commits, any session
   may take the task over and must note the handoff in the log.
